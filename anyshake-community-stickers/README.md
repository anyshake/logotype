# AnyShake Community Stickers

A community sticker set inspired by AnyShake products.

## Contents

- `stickers/`: Ready-to-use PNG files with transparent backgrounds.
- `sources/`: Editable Procreate source files.

Each sticker and its source file share the same numbered filename.
